离职审批 · web 原型（带批注）

web 分两摊——「发起与处理」是员工和审批侧在既有 OA 菜单里做的事（发起审批、待我处理，不新增菜单），「离职管理」是 HR 和管理员在人事菜单里做的事（类型配置、离职管理、员工档案）。顶部切换角色查看，屏幕为浏览器窗口示意，仅静态展示。

仅静态展示，不可点击
web 复用既有 OA 菜单：发起与处理不新增菜单，入口就在「发起审批」「审批任务」里
