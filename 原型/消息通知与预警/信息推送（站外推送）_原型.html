原型说明：
1. 站外形态 = 手机系统通知（App 系统通知），出现在锁屏 / 通知栏；本原型展示通知栏下拉态。
2. 文案与站内消息中心完全一致（含还款预警常规 / 临近 / 逾期 / 已还款各档，申请人侧与会计侧两条不同文案），不另写一版。
3. 点击通知 → 打开 App 并定位到对应通知 / 流程详情；打开后站内对应通知置为已读，跨端同步。
4. 站外通知仅推送文案，不携带敏感信息。
5. 六类通知统一接入（@我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 / 还款预警），不提供按类开关。
6. 外观约束：系统通知只能呈现应用图标（图标本身可彩色）、应用名、时间、正文文本，没有彩色左边条、也没有彩色分类标签。阶段（常规 / 临近 / 逾期）由正文文案自带（如「剩余 183 天」「已逾期 3 天」），不靠颜色区分；站内消息中心的蓝 / 橙 / 红 / 绿配色仅用于站内卡片，不会出现在手机系统通知里。
7. 两页分工：上方第一台手机展示还款预警的多种阶段与申请人侧 / 会计侧文案差异；第二台手机为六类通知完整清单（@我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 / 还款预警 各一条），六类均已接入 App 系统通知、均在原型中呈现。
