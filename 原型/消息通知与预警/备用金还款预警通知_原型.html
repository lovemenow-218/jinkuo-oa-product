备用金还款预警 · 全页面原型 v2
本版替换旧原型，覆盖预警功能全部页面：h5 通知列表（申请人 / 会计两态）→ h5 详情弹层 → web 消息中心（卡片 + 详情弹窗）→ web「预警管理」列表 / 详情（部门筛选、批量确认）。
本版关键变更：① h5/web 点击卡片改为弹出详情弹层 / 弹窗，不再直接跳页；② 会计侧在详情内完成【确认已还款】；③ 已还款后进入只读回执态。
屏 0 · 预警功能页面地图本次原型覆盖的全部触点
h5
① 通知列表 · 第 5 类「还款预警」

申请人侧 / 会计侧两套列表样式（与《消息通知优化》原型通知列表同款外观）；蓝 / 橙 / 红 / 灰四态；点击行 → 详情弹层，会计侧在弹层内【确认已还款】。见屏 1。

h5
② 预警详情弹层

半屏弹层（非页面跳转）。会计侧：【确认已还款】；申请人侧：仅信息、无操作；已还款后点击卡片：只读回执（确认人 / 确认时间）。见屏 2。

web
③ 消息中心 · 还款预警卡片 + 详情弹窗

卡片带阶段 / 档位标签；点击弹详情弹窗：会计侧提供【确认已还款】，弹窗底部「查看流程详情」。见屏 3。

web
④ 预警管理 · 列表页

下版本新建。筛选（状态 / 阶段 / 申请人 / 部门 / 时间）+ 列表（含部门列）+ 勾选批量确认。见屏 4。

web
⑤ 预警管理 · 详情抽屉

档位触发时间线（逾期按天堆叠）、当前状态与确认操作。见屏 5。
