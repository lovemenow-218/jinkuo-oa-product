附 · 口径速查（非页面）阶段 / 状态 / 入列 / 权限 / 导出
阶段与状态的关系（列表两列并存，阶段为细、状态为粗）
常规 / 临近 → 状态「预警中」　｜　逾期 → 状态「已逾期」　｜　已还款 → 状态「已还款」
「当前阶段」四值：常规（剩余 > 7 天，含尚未触发任何档位的长周期单）/ 临近（剩余 0~7 天）/ 逾期（已过还款日）/ 已还款（终态）；不显示「—」。

入列口径：单据全部审批通过、进入预警监控即入列（含已还款终态），长周期备用金全程可见；预警起始时间 = 办结进入监控时间，不要求已产生通知记录。
权限：菜单仅会计审批处理人及相关管理角色可见；管理角色仅查看台账，不拥有「确认已还款」权限；确认严格绑定该笔单据的会计审批处理人。
排序：支持预警起始时间 / 还款日期 / 剩余·逾期天数 / 金额 / 申请人，默认按剩余·逾期天数升序；排序状态与导出联动。
导出：Excel（.xlsx），范围 = 当前筛选 + 排序结果，文件名 备用金预警_{筛选摘要}_{导出时间}.xlsx。
已读：已读仅属消息中心「还款预警」类通知；本页时间线为只读台账，查看不触发已读变更；确认已还款不改变任何通知已读状态。
不做：本期不提供申请人信息（部门）编辑、不含预警档位配置入口、不承载推送配置；所属部门为申请单手填快照值，修正走申请单源头。
