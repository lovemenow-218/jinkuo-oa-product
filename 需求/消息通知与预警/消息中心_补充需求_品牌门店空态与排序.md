**需求描述**

**消息中心 - 品牌 / 门店空态展示（h5 / App）**

· 品牌下门店全部无未读时，该分组头合计为 0，分组仍展示、不自动隐藏，0 以弱化样式呈现、不计入全站总数；
· 当前登录人所有品牌、所有门店均无未读时，消息首页仍整列展示全量品牌分组结构与各门店行，不隐藏、不收起为「无通知」整列空状态；
· 「无通知」空状态仅在该用户点进某门店消息页、且该门店自身零消息时展示于门店消息页，不作用于消息首页整列；
· 空态分组的弱化样式不改变分组头结构（品牌标识、品牌名、「N 家门店 · 共 0 条消息」、右箭头均保留）。

**消息中心 - 默认展开 / 折叠态（h5 / App）**

· 进入消息首页，品牌分组默认态按未读合计判定：合计未读 > 0 → 默认展开；全 0 → 默认折叠（仅展示分组头）；
· 门店子级随父级：父级展开则门店全列、不二次折叠；父级折叠则仅展示分组头，点击展开即列出全部门店行；
· 不提供全局「全部展开 / 全部折叠」开关；
· 不记忆用户手动展开 / 折叠状态，每次进入消息首页均回到上述默认态，跨会话不持久化。

**消息中心 - 排序兜底规则（h5 / App）**

· 排序主规则沿用既有口径：品牌分组按合计降序；同组内门店按角标降序，角标相同按最新消息时间倒序（时间新的在前）；
· 当角标相等、且最新消息时间缺失（该门店无任何消息历史）或相等（多条门店最后消息同秒产生）时，启用名称兜底排序，确保顺序 100% 确定、不依赖数据库返回序、不随机跳序；
· 名称兜底排序规则：中文品牌名 / 门店名按拼音首字母排序（金 jīn → J、阔 kuò → K；首字母相同再比后续拼音）；名称中的阿拉伯数字按自然排序（门店2 < 门店10，非字典序门店10 < 门店2）；中英文混排时中英文按各自拼音 / 字母规则并入同一序列比较；
· 品牌级全 0（所有品牌合计相等）时，品牌分组之间按品牌名拼音首字母兜底排序；
· 门店级全 0（同组内所有门店未读均为 0）时，门店之间按门店名拼音首字母兜底排序，无历史的 null 时间门店不再置底悬空，统一并入名称序。
