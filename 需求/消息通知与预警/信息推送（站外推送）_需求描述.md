**需求描述**

**信息推送（站外推送）**

背景与现状：系统已有信息推送能力，原覆盖「他人流程提交时对应处理人收到一条通知」的审批待办类站外提醒；消息通知体系（站内）已全面，含 @我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 / 还款预警 六类；本需求将站内六类通知统一接入现有站外推送通道，使对应接收人在系统外（手机系统通知 / 类微信消息）也能收到提醒，不必打开 App 或网页查看站内消息；

推送类型清单（六类，与站内消息中心一致）：

@我的：站内文案「XXX 在【流程名称】中@了你」，站外同文案；接收人 = 被@人；

审批通过：站内文案「【流程名称】已审批通过」，站外同；接收人 = 流程发起人；

审批驳回：站内文案「【流程名称】已被驳回」，站外同；接收人 = 流程发起人；

抄送我的：站内文案「【流程名称】已抄送给你，可查看审批进度」，站外同；接收人 = 抄送人；

待我审批：站内主文案「【提交人】提交了【流程名称】，请处理」，站外同；接收人 = 节点待审批处理人；

还款预警：站内含常规提醒 / 临近提醒 / 逾期提醒 三档位与每日逾期提醒；站外同档位同文案；接收人 = 申请人与会计审批处理人；该类下另含会计审批处理人确认已还款后向申请人发送的「还款完成」通知（每单一条），站外同文案，接收人 = 申请人；

推送文案：各类站外文案与站内消息中心完全一致，不另行编写；

接收人：与站内对应通知的接收人完全一致（@我的→被@人，审批通过→发起人，审批驳回→发起人，抄送→抄送人，待我审批→节点处理人，还款预警→申请人 + 会计审批处理人）；不向无关人推送；

推送频率与去重：

每类通知按站内相同频率触发（审批通过 / 驳回各一次、待我审批每流转一次、还款预警按档位一次 + 逾期每日一条、「还款完成」每单一次）；逾期每日提醒站外与站内同频（每日一条），不做降频；

同单据、同节点、同接收人不重复堆积；与站内共用幂等标识，避免站外重复推送；

还款预警逾期每日提醒的文案随逾期天数逐日递增（如「已逾期 1 天」→「已逾期 2 天」），内容天然不同、不存在重复文案；沿用现有 App 系统通知通道的幂等 / 去重能力即可，预警侧不额外实现幂等 / 去重；联调时确认通道侧不重复下发；

高频场景（如审批流转反复）按站内频控，不额外加码；

已读同步：站外推送被点击打开后，站内对应通知自动置为已读（h5 / web 跨端同步）；站内已读的通知不再重复推送该条；

已还款终止（还款预警类）：该笔单据被确认已还款后，立即停止其后续所有站外推送（与站内终止逻辑一致）；

通道形态：沿用现有信息推送通道，不新增通道类型；本期明确为 **App 系统通知（手机系统通知）** 单一通道，不提供微信模板消息 / 短信通道；

免打扰 / 推送开关：沿用系统 / 现有推送的免打扰与开关策略；本需求 **不新增分类型推送开关**（不提供「仅推待我审批与预警、关闭 @我 / 抄送」等按类开关），六类通知统一接入；

范围说明：本需求聚焦「将站内六类通知接入站外推送」，不改动站内消息中心逻辑、不新增通知类型、不新增推送通道；

**附：已确认决策与已知说明**

已确认决策（用户拍板，2026-11-04）：

1. 分类型推送开关 / 免打扰：**不做**。不新增按类型开关，六类通知统一接入，沿用系统现有免打扰策略；

2. 站外通道形态：**App 系统通知（手机系统通知）**，不提供微信模板消息 / 短信通道；

3. 幂等 / 去重 / 频控：沿用现有 App 系统通知通道能力，预警侧不额外实现；还款预警逾期每日提醒文案随逾期天数逐日递增，内容天然不同、不存在重复下发，联调时确认通道侧不重复推送即可；

4. 推送文案：**直接复用站内消息中心文案**，本需求不重定义（示例见下表）；

推送文案示例（以下为站内消息中心原文，站外 App 系统通知直接复用，不另写）：

| 类型 | 接收人 | 站内 / 站外文案 |
|------|--------|----------------|
| @我的 | 被@人 | XXX 在【流程名称】中@了你 |
| 审批通过 | 发起人 | 【流程名称】已审批通过 |
| 审批驳回 | 发起人 | 【流程名称】已被驳回 |
| 抄送我的 | 抄送人 | 【流程名称】已抄送给你，可查看审批进度 |
| 待我审批 | 节点处理人 | 【提交人】提交了【流程名称】，请处理 |
| 还款预警 · 常规提醒 | 申请人 | 【备用金申请】将于 {还款日} 到期，剩余 {剩余天数} 天，请及时还款 |
| 还款预警 · 临近提醒 | 申请人 | 文案同常规提醒（阶段标签为「临近提醒」，剩余天数在 [0,7] 区间） |
| 还款预警 · 到期当天 | 申请人 | 【备用金申请】今日 {还款日} 到期，请立即还款 |
| 还款预警 · 逾期提醒 | 申请人 | 【备用金申请】已于 {还款日} 逾期 {逾期天数} 天，请立即还款 |
| 还款预警 · 逾期提醒 | 会计审批处理人 | 【备用金申请】申请人 {姓名} 尚未还款 {金额}，还款日 {还款日}，已逾期 {逾期天数} 天，请关注 |
| 还款完成 | 申请人 | 【备用金申请】{金额}，还款日 {还款日}，已由会计审批处理人 {确认人姓名} 于 {确认时间} 确认还款 |

已知说明：

站外推送仅推送文案，不携带敏感信息；
