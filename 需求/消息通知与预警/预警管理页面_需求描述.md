**需求描述**

**预警管理页面（web 管理后台，下版本新建）**

**页面入口**

入口：web 管理后台新增「预警管理」一级菜单，按权限点控制可见性，仅会计审批处理人及相关管理角色可见（权限模型与预警通知中的「确认已还款」操作一致）；

页面定位：作为预警通知（消息中心「还款预警」类）的统一管理入口与跳转目标；预警通知卡片点击由「暂跳流程详情」切换为跳转到本页面；

**列表页**

列表字段：流程名称、申请人、所属部门（申请单「借款人所属部门」快照值）、备用金金额、还款日期、剩余天数 / 逾期天数、当前阶段（常规 / 临近 / 逾期；尚未触发任何档位提醒的单据归入「常规」，不显示「—」；已还款单据该列显示「已还款」）、状态（预警中 / 已逾期 / 已还款）、预警起始时间（该笔单据办结、进入预警监控的时间）；

入列与阶段判定：「预警管理」列表为备用金还款的统一管理台账，单据全部审批通过、进入预警监控即入列（即便尚未触发过任何一条档位提醒，如<span style="color:#c00000">还款期 365 天的单据在前 255 天无任何提醒</span>也会持续在列，使长周期备用金全程可见，而非等首条提醒冒出才出现）；「当前阶段」为按当前日期实时派生的单据维度值（非取自某条通知记录，列表为一单一行、通知按天堆叠多条），判定规则：① 已确认还款 → 显示「已还款」；② 当前日期已过还款日 →「逾期」；③ 剩余天数在 [0, 7] 天（含到期当天及 7/1/0 档区间）→「临近」；<span style="color:#c00000">④ 剩余天数 > 7 天（处于 R 提前 30% 档或 30 档区间）→「常规」；</span>⑤ 尚未触发过任何档位提醒（剩余天数远超首个档位阈值）→ 归入「常规」（状态仍为「预警中」，一并纳入「常规」阶段桶）；

状态覆盖：列表加载中、加载失败可重试、空状态（无任何预警）、筛选无结果空状态均需有设计；支持分页；

**查询框位置与筛选**

列表筛选：按状态（预警中 / 已逾期 / 已还款）、按阶段（常规 / 临近 / 逾期 / 已还款 四桶；未触发档位的单据归入「常规」桶）、按申请人、按所属部门、按时间范围；支持流程名称 / 申请人关键字搜索；

所属部门为申请单提交时手工填写的文本值（非组织架构结构化数据，可能存在同名异写），筛选与搜索按「包含匹配」实现，不做标准化映射；

**列表排序**

列表排序：支持按关键列排序，至少包含预警起始时间、还款日期、剩余天数 / 逾期天数、备用金金额、申请人；点击列头切换升序 / 降序，默认按「剩余天数 / 逾期天数」升序（最紧急、逾期最久的在前）；排序状态与下方导出联动。

**列表导出**

列表导出：列表支持导出当前查询结果。导出格式为 Excel（.xlsx）；权限与列表可见性一致（仅会计审批处理人及相关管理角色可操作）；导出范围 = 当前筛选条件 + 排序后的全部结果（即上方查询 / 筛选后导出对应数据，而非强制全量）；导出文件名按以下规则生成：

格式：`备用金预警_{筛选摘要}_{导出时间}.xlsx`；

筛选摘要：未筛选时为「全部」；已筛选时按生效维度拼接（状态 / 阶段 / 申请人 / 部门 / 时间范围），如 `已逾期_赵敏`；

导出时间：`YYYYMMDD_HHMMSS`（24 小时制，防重）；

示例：`备用金预警_已逾期_赵敏_20261104_153000.xlsx`。

**详情抽屉**

预警详情：进入某笔单据查看其全部预警记录，以时间线形式展示各档位触发记录（档位、触发日、文案摘要）与按天堆叠的逾期每日提醒（逐条标注当日逾期天数），并展示当前确认状态；

**确认已还款弹窗**

确认已还款：列表与详情均提供「确认已还款」操作，仅该笔单据的会计审批处理人可见，权限与消息中心一致；管理角色虽可进入本页面查看台账，但不具备「确认已还款」操作权限（确认权限严格绑定该笔单据的会计审批处理人）；点击弹二次确认弹窗（展示流程名称、申请人、金额、还款日期、当前逾期天数，未逾期时该项显示「—」），明示「确认后停止所有预警与逾期提醒且不可撤回」；确认为终态，不可撤回；确认成功后向该笔单据的申请人发送「还款完成」通知，规则沿用《备用金还款预警通知》；

**批量确认弹窗**

批量确认：列表支持勾选多行后批量确认已还款（仅对当前用户为会计审批处理人、且有确认权限的单据生效；无权限行置灰不可勾选）；批量确认前弹窗汇总所选单据并明示「确认后各笔均停止预警与逾期提醒且不可撤回」，逐笔生效、部分失败时给出失败清单；批量确认为逐笔独立确认，每笔成功后均向对应申请人各发送一条「还款完成」通知，互不影响；

**已读联动**

已读联动：已读状态为消息中心「还款预警」类通知的属性，口径与《备用金还款预警通知》一致——在消息中心点击某条预警通知打开详情时仅将该条置为已读，该笔单据其余未读通知（含按天堆叠的逾期每日提醒）保持未读，需逐条打开或在消息中心批量已读；预警管理页面的详情时间线为台账只读视图，不作为已读实体，查看时间线不触发任何通知的已读变更；确认已还款操作不改变任何通知的已读状态；

**数据来源与口径**

数据来源与口径：与预警通知完全一致（数据源为备用金申请会计审批还款日期、需全部审批通过、档位规则系统自动计算、每日 10:00 扫描）；即全部审批通过、进入预警监控的备用金单据均纳入列表（含已还款终态单据；已还款仅改变其当前阶段与状态，不将其移出列表），「预警起始时间」为该单据办结、进入预警监控的时间，不要求已产生过任何通知记录（见「入列与阶段判定」）。

**附：已知说明**

预警管理页面为下版本新建功能，立项后预警通知（消息中心「还款预警」类）点击跳转由「暂跳流程详情」切换为本页面；预警通知本身仍在消息中心承载，两者并存，不互相替代；

本期预警管理页面不含预警档位配置入口，档位规则沿用系统自动计算（与预警通知一致）；

本期预警管理页面不承载推送配置，推送相关需求见《信息推送（站外推送）》；

权限模型、确认已还款终态规则与颜色沿用《备用金还款预警通知》既有定义；「当前阶段」取值以本页「入列与阶段判定」规则为准（常规 / 临近 / 逾期 / 已还款，不显示「—」），不与《预警通知》的「常规提醒 / 临近提醒 / 逾期提醒」通知档位名称混用；

涉及的单据表单名称统一为「备用金申请」；

所属部门为申请单提交时手工填写的文本快照，非标准化组织架构数据；后续如需按部门做严格汇总统计，需评估将表单字段改为组织架构下拉选择（另立需求）。
