**需求描述**

**会计审批 - 是否签订**

在会计审批表单的"选择帐套"字段上方，新增【是否签订】下拉框，选项为"是"、"否"，默认为空（必填，不预选）；

点击【是否签订】下拉框 → 展开选项"是"/"否" → 选择"是"时，在【是否签订】下方显示【合同关联】与【合同收款账号】两个字段；

选择"否"时，隐藏【合同关联】与【合同收款账号】两个字段，并清空已选值；

未选择（保持为空）时，不展示【合同关联】与【合同收款账号】，也不触发任何历史数据改判处理；

注意：由"是"改回"否"或清空时，已选的合同关联与合同收款账号须一并清除，避免脏数据随表单提交；提交校验在"否"或为空时不校验这两个字段。

**会计审批 - 合同关联**

点击【合同关联】字段 → 弹出合同关联选择弹窗（样式见组件：卡片列表，每条含单行文本、申请款项、数字等字段）；

弹窗内以卡片列表展示可选合同，点击卡片选中（选中项左侧蓝色竖条高亮），点击【确定】回填合同信息至【合同关联】字段，点击【取消】或 × 关闭则不回填；

【合同关联】回填后在表单中以文本/摘要形式展示所选合同（如合同名称或编号），未选择时占位"请选择合同"；

合同关联为单选，当前组件为单选卡片，一次仅可选定一个合同；

注：合同关联弹窗的字段列含义（单行文本 / 申请款项 / 数字）、数据来源接口与搜索分页规则均由合同关联组件自身配置决定，本需求不额外定义（属组件设置范畴，不在本需求范围内确认）。

**会计审批 - 合同收款账号**

点击【合同收款账号】字段 → 弹出银行账户选择弹窗（样式见组件：顶部"添加银行账户"入口 + 账户卡片列表，每张卡片含卡号、户名、银行、支行、备注，卡片右上角可编辑）；

弹窗内展示已保存的银行账户卡片，点击卡片选中并回填至【合同收款账号】字段；点击卡片右上角编辑图标可修改该账户；点击顶部"添加银行账户"可新增账户（弹窗含户名、卡号、银行、支行、备注，底部取消/提交）；

"添加银行账户"提交后，新增账户仅进入账户列表待选，不立即回填至字段，需用户点选卡片才回填；

【合同收款账号】回填后在表单展示所选账户（卡号 + 户名），未选择时占位"请选择收款账号"；

注：合同收款账号与表单原有"选择账户"字段语义不同、不共用数据源——前者为本需求新增的合同维度收款账号，后者为原有会计办理账户，二者分别回填、互不干扰。

**会计审批 - 字段顺序与必填**

字段自上而下顺序为：【是否签订】→（是否签订=是时）【合同关联】→（是否签订=是时）【合同收款账号】→【选择帐套】→【选择账户】→ 会计审批意见 → 附件；注：原有"选择帐套""选择账户"位置不变，新字段仅插入其上方；

【是否签订】为必填；【合同关联】【合同收款账号】仅在【是否签订】= 是 时为必填且可见，= 否 或为空 时非必填且隐藏；

注意：本需求新增字段仅在当前供应商及合同款项会计审批页面展示，不扩展到其他会计审批表单。

**会计审批 - web 与 h5 双端一致**

web 端"同意会计审批"弹窗与 h5 端"审批"页同步新增上述字段，字段顺序、联动逻辑、必填规则双端保持一致；

两端【合同关联】【合同收款账号】均以弹窗选择器形式呈现（不改为内联），样式分别复用合同关联弹窗与银行账户选择弹窗组件；

注意：web 端、h5 端字段标签统一使用"帐套"（原 h5 端"账套"统一改为"帐套"）；h5 端原"选择帐套"上方存在一段空白条（疑似隐藏字段占位），新字段应衔接该区域，消除遗留空白。
