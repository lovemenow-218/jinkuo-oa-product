> 来源：已落地的 UI 用例 `tests/web/ui/test_ui_write3.py` 类 A（41/41 全绿），手册步骤与真实前端一一对应。

## 2. 第一步：新增采购计划

| 操作 | 位置 / 按钮 | 输入内容 |
|------|------------|---------|
| 进入页面 | 地址栏直接访问 `https://oacs.fzjinkuo.com/warehouse/purchase-plans`，或左侧菜单进「采购计划」列表 | — |
| 点新增 | 列表页右上「**新增采购计划**」按钮 | — |
| 填名称 | 弹窗内「采购需求名称」输入框（占位「请输入采购需求名称」） | 任意，例如 `手动测试采购计划0111` |
| 选仓库 | 弹窗内「**需求仓库**」下拉 | 选 `1010出库仓`（或任意启用仓库） |
| 加物料 | 弹窗内「**添加物料**」按钮 | — |
| 搜物料 | 物料选择弹窗内搜索框（占位「物料名称 / 编码」） | 填 `测试物料A` → 等结果出来 |
| 勾物料 | 搜索结果第一行左侧复选框（点小方块） | — |
| 确认物料 | 物料弹窗「**确定**」按钮 | — |
| 填数量 | 回到计划弹窗，明细行里的数量输入框（该行第 2 个输入框） | 填 `5`（任意正整数） |
| 填期望到货 | 弹窗内「**期望到货日期**」日期框 | 填 `2027-12-31`，回车 |
| 保存 | 弹窗内「**保存**」按钮 | — |

**预期结果**：弹窗关闭、回到列表。在列表搜索框（占位「请输入计划名称」）填你起的名字 → 点「查询」，应能搜到这条新计划：
- 计划单号以 **`CK`** 开头；
- 状态为 **「待审核」**。

> 提示：计划号形如 `CK2026xxxxxxxxxxxxxxxx`，记下它，后面两步都要用它来检索。

## 3. 第二步：审核采购计划

| 操作 | 位置 / 按钮 | 输入内容 |
|------|------------|---------|
| 检索 | 列表搜索框填计划名称 → 点「查询」 | — |
| 点审核 | 该行操作列「**审核计划**」按钮 | — |
| 填原因 | 弹出的 message-box（确认框）里的输入框/文本域 | 任意原因，例如 `手动测试：审核通过` |
| 确认 | message-box 内「**确认审核计划**」按钮 | — |

**预期结果**：message-box 关闭，列表里该计划状态变为 **「已审核」**。
（用例同时校验"审核后产生下单余量 remainingQuantity > 0"，手动可不必深究，只要状态变了就对了。）

⚠️ **卡点处理**：若点击「审核计划」后系统提示「创建人不能审自己」类拦截，说明本环境该审批节点要求换人：
1. 退出当前账号，用备用账号 `18006931939` / `18006931939`（陈林）重新登录；
2. 进同一采购计划列表，搜到该计划，重复上面的"点审核 → 填原因 → 确认审核计划"。
（注：本仓库自动化用例用同一主账号自审是通过的，但不同部署/数据下可能启用跨人校验，按提示换人即可。）

## 4. 第三步：生成采购订单

| 操作 | 位置 / 按钮 | 输入内容 |
|------|------------|---------|
| 检索 | 列表搜索框填计划名称 → 点「查询」 | — |
| 点生成 | 该行操作列「**生成采购订单**」按钮（仅「已审核」状态才出现） | — |
| 选供应商 | 弹窗内「**供应商**」下拉 | 选下拉里任意一项（第一项即可） |
| 保存 | 弹窗内「**保存**」按钮 | — |

**预期结果**：弹窗关闭，系统生成一张新的**采购订单**：
- 订单状态为 **「待审核」**；
- 订单的"来源单据"回链到刚才那个采购计划（即 `sourceDocumentId` = 计划 documentId）；
- 订单号同样以 **`CK`** 开头。

> 到此，「采购计划全流程」走完。若想继续「订单审核 → 入库」，属于另一条链路（由 `test_ui_write2.py` 覆盖），本手册不含。

## 6. 常见问题 / 卡点速查

| 现象 | 原因 / 处理 |
|------|------------|
| 一直停在登录页、弹「请同意协议」 | 没点到"同意"的**方框**，只点了文字。重新点小方块再登录。 |
| 打开的是 h5 移动端样式 / 地址是 `h5cs` | 入口用错了，必须是 `oacs.fzjinkuo.com`（web 后台）。 |
| 搜不到 `测试物料A` | 物料名区分大小写/空格；确认测试环境数据未清。可改搜 `物料` 关键字挑一个存在的。 |
| 审核提示「创建人不能审自己」 | 见第 3 步卡点处理，换 `18006931939` 登录审核。 |
| 「生成采购订单」按钮不出现 | 计划还没「已审核」；先完成第 3 步。 |
| 保存后列表搜不到新订单 | 正常——订单挂在「采购订单」列表（按计划号搜不到），可去采购订单页按来源计划号或时间找。 |
