## 1. 基础建档

> 真实菜单在左侧「**基础档案**」分组（部分在「**系统设置**」「**申购与供货**」）。建档只需做一次，后续开单共用。

**商品类别档案**
- 菜单：左侧 `基础档案` → `商品类别档案`（路由 `/warehouse/profiles/categories`）
- 操作：点「**新增类别**」→ 填「类别名称」「规格」「基础库存单位」→ 保存。
- 预期：列表出现新类别，后续开单能选到；停用后的类别不能被选用。
- **账号**：主账号 `15060038842`（陈林航，建档类动作，用谁建都行，统一用主账号）。

**商品档案（建商品本体，单位换算/开单的前置）**
- 菜单：左侧 `基础档案` → `商品档案`（路由 `/warehouse/profiles/goods`）
- 操作：点「**新增商品**」→ 弹窗填写：
  - `商品名称`（**必填**，最多 40 字，如「测试物料A」）
  - `商品类别`（下拉选本小节上方建的类别）
  - `规格`（如「500ml/瓶」，可选）
  - `基础库存单位`（库存计数基础单位，如「件 / 瓶 / 个」）
  - `包装单位换算`（可选，关联已建的单位换算；见本小节下方「物料单位换算」）
  - `默认供应商`（可选，关联供应商档案）
  - `状态` 启用；`商品编码` 留空自动生成。
- 预期：列表出现新商品，后续「添加物料」「单位换算」都能选到该商品。
- **账号**：主账号 `15060038842`（建档类动作）。
- ⚠️ **必须先建商品档案**：第 1 节「物料单位换算」选的「物料」就是这里建的商品；采购计划/申购单「添加物料」也依赖此商品。没有商品，单位换算和开单都选不到物料。

**仓库档案**
- 菜单：左侧 `基础档案` → `仓库档案`（路由 `/warehouse/profiles/warehouses`）
- 操作：点「**新增仓库**」→ 填仓名、勾选用途（供货仓 / 发货仓 / 申购方收货仓）→ 保存。
- 预期：各自只能选到本机构有权限的仓库；本链路至少需要「一个供货/发货仓」+「一个申购方收货仓」。
- **账号**：主账号 `15060038842`（建档类动作）。
- ⚠️ 环境里通常已存在启用仓库（如 `1010出库仓`），可复用，不必每次新建。

**供应商档案**
- 菜单：左侧 `基础档案` → `供应商档案`（路由 `/warehouse/profiles/suppliers`）
- 操作：点「**新增供应商**」→ 填名称等 → 保存。
- 预期：采购订单能选到该供应商。（采购入库单认的是**供应商档案**，不是商家本身。）
- **账号**：主账号 `15060038842`（建档类动作）。

**物料单位换算**
- 菜单：左侧 `基础档案` → `物料单位换算`（路由 `/warehouse/units`）
- 操作：点「**新增换算**」→ 基础单位填「**件**」，业务单位补「**箱**」（如 1 箱 = N 件）→ 保存。
- 预期：换算关系与数量精确度生效；同一物料的换算关系**不能重复**。
- **账号**：主账号 `15060038842`（建档类动作）。
- ⚠️ 换算的「物料」下拉选的是本小节上方「**商品档案**」里建的商品，务必**先建商品再配换算**；同一物料的换算关系不能重复。

**履约人员配置（= 截图「操作人配置」）**
- 菜单：左侧 `系统设置` → `履约人员配置`（路由 `/warehouse/roles`）
- 操作：配置「审核人 / 发货人 / 收货人」对应的账号与角色权限。
- 预期：有权限的人可办对应环节；无权限的人操作被拦。
- **账号**：主账号 `15060038842`（配置履约人员/权限，用管理员账号）。
- ⚠️ 本环境主账号 1506 是 `sy-org-admin`（通常具备全部权限），跨人次账号 1800 用作受限审批人。若你要验证「无权限不能操作」，用 1800 去点它没被授权的动作即可。

**申购协议（建档收尾，也是第 2 节的 precursors）**
- 菜单：左侧 `申购与供货`（或 `仓库管理`）→ `申购协议`（路由 `/warehouse/requisition-agreements`）
- 操作：点「**新增协议**」→ 弹窗填写：
  - `协议名称`（如「链路测试申购协议」）

  - 保存。
- 预期：协议出现在「新建申购单」的协议候选里；无协议或协议失效时不能继续开申购单。
- **账号**：主账号 `15060038842`（建档/配置类，用主账号）。

## 2. 申购（申购申请单 + 四级审核）

**新增申购**
- 菜单：左侧 `申购与供货` → `申购申请单`（路由 `/warehouse/requisitions`）
- 操作（用**主账号 1506** 登录）：
  1. 点「**新增申购**」→ 选「**发货机构**」+ 有效的「**申购协议**」。
  2. 加物料：选「测试物料A」，**申请数量 10 件**，单位「件」，单价/金额自动带出（来自协议默认价）。
  3. 核对：数量、单位、价格、金额、**申购日期**、**需要到货日期**。
  4. 点「**保存**」→ 再点「**提交**」（进入审核流）。
- 预期：列表出现新单，单号 `CK` 开头，状态「**待审核**」。
- **账号**：主账号 `15060038842`（发起申购，建单方）。

**四级审核（门店 → 订单 → 收款 → 财务）**
- ⚠️ 审核必须用**跨人次账号 1800** 登录（创建人自审必被拒）。
- 四个审核页（左侧 `申购与供货` 下）：
  - `门店审核` `/warehouse/requisition-review-store`
  - `订单审核` `/warehouse/requisition-review-order`
  - `收款审核` `/warehouse/requisition-review-receipt`
  - `财务审核` `/warehouse/requisition-review-finance`
- 操作：每级进入对应审核页 → 找到该单 → 点「**审核通过**」（或「同意」）并填审核意见 → 逐级推进。
- 预期：状态依次走 `待门店审核 → 待订单审核 → 待收款审核 → 待财务审核 → 已审核`。
- **账号**：跨人次账号 `18006931939`（陈林，审核方；**不能用**创建人 1506 自审，否则 403/409）。
- ⚠️ **审核人不能是单据创建人**（实测 403/409）；「各级审核人不能越权」也是截图检查项。
- ⚠️ 提交/审核**都不会**自动收货或入库，只是推进单据状态。

**付款登记与到账确认（发货前置，若走资金流）**
- 进入申购单详情 → `付款记录` 页签 → 点「**添加付款记录**」（状态「已审核」时才可点，`canCreate=true`）。
- 登记（主账号 1506）：填付款时间、方式（如银行转账）、金额（=单据金额）、上传凭证 → 保存。
- 确认到账（**必须换 1800 登录**）：在付款记录里点「**确认到账**」。
- ⚠️ 三权分立：**登记人不能自己确认到账**（本人确认实测 403「不能确认本人提交的付款凭证」）。
- 预期：付款状态变「已付款」，解锁后续发货。
- **账号**：登记用主账号 `15060038842`；确认到账**必须换**跨人次账号 `18006931939`（三权分立，本人确认被 403「不能确认本人提交的付款凭证」）。

## 3. 采购补货（扩展路径，供货方缺货时才需要）

> 截图明确：采购计划属于**扩展路径**；基础链路是系统支持的**独立采购订单**。若供货方（本店）已有库存，可跳过本节直接到第 4 节发货。

**采购计划**
- 菜单：左侧 `采销管理`（或 `仓库管理`）→ `采购计划`（路由 `/warehouse/purchase-plans`）
- 操作（实测 UI）：点「**新增采购计划**」→ 填「采购需求名称」→ 选「**需求仓库**」→ 点「**添加物料**」选物料、填数量 → 填「**期望到货日期**」→ 「**保存**」。
- 审核：列表该行点「**审核计划**」→ 弹窗**填审核原因** → 点「**确认审核计划**」（动作底层为 `plan_approve`）。
- 下推：已审核计划该行点「**生成采购订单**」→ 选供应商 → 保存，生成采购订单。
- 预期：计划状态 `待审核 → 已审核`；计划/订单**均不增加库存**；已审核才出现「生成采购订单」。
- **账号**：计划由主账号 `15060038842` 新建；**审核计划**须换跨人次账号 `18006931939`（创建人不能审自己）。

**采购订单**
- 菜单：左侧 `采销管理` → `采购订单`（路由 `/warehouse/purchase-orders`）
- 操作：点「**新增采购**」→ 选供应商、选物料（**采购 10 件**）、核对单价/数量/金额 → 保存 → 审核（走采购订单的审核动作，或对应审核入口）。
- 预期：未发、数量/价格正确；**订单审核后库存仍不增加**。
- **账号**：主账号 `15060038842`（建单/审核采购订单）。

**采购入库单**
- 菜单：左侧 `采销管理` → `采购入库单`（路由 `/warehouse/purchase-receipts`）
- 操作：按采购订单收货 → 选「**入库仓库**」→ 保存 → 「**完成审核**」（过账动作 `approve`）。
- 预期：审核成功后**供货仓库存 +10 件**；订单/收货进度同步更新。
- **账号**：主账号 `15060038842`（收货过账）。
- ⚠️ 采购入库认的是**供应商档案**（传商家 id 200242 会 400「供应商不存在」）。

## 4. 供货出库（供货方发货）

**新增发货**
- 菜单：左侧 `申购与供货` → `供货发货与收款`（路由 `/warehouse/supply-orders`；即截图「供货方发货单」）
- 操作（用**主账号 1506**；前置：申购单已审核 + 已付款/或跳过付款看配置）：
  1. 点「**新增发货**」→ 选「**发货仓库**」（供货仓）。
  2. 填「**发货日期**」「**承运信息**」「**运单号**」。
  3. 本次发货数量填 **10 件**（不能超过订单剩余可发量）。
  4. 点「**确认发货**」。
- 预期：发货成功，生成发货单；**供货仓库存 10 → 0**；申购方尚未签收、其库存仍为 0。
- **账号**：主账号 `15060038842`（供货方发货）。
- ⚠️ 超量或 0 量会被拦（接口 400「不能超过订单剩余可发数量」）；同一 requestKey 重发会复用原单（幂等，不会重复扣）。
- ⚠️ 申购方「预发货数」允许、不可重复、不能取消已用库存；重复操作不会重复扣库存。

## 5. 申购方签收入库（配送签收）

**配送签收**
- 菜单：左侧 `申购与供货` → `申购入库单`（路由 `/warehouse/requisition-receipts`；即截图「配送签收/售后」）
- 操作（用**主账号 1506** 或收货人账号）：
  1. 打开对应的申购单/发货单 → 进入「**配送签收**」。
  2. 选「**收货仓库**」（申购方收货仓）。
  3. 在明细行填四项（**四项合计必须等于发货量 10**）：
     - `合格收` = 10（示例：合格 10 / 短少 0 / 破损 0 / 拒收 0）
     - 或差异示例：合格 8 / 短少 2 / 破损 0 / 拒收 0（四舍五入后等于发出 10）
  4. 若有差异（短少/破损/拒收 > 0），**必须填「差异原因」并选择「补发」或「差异结案」**（不填会拦，红字「请填写差异原因」）。
  5. 点「**确认收货**」。
- 预期：
  - **只有「合格数」增加库存**（如合格 8 → 收货仓 +8）；短少/破损/拒收不入库。
  - 差异进入后续处理（差异单），由 `差异单` 菜单承接。
  - 来源信号（仓库/物料/数量/收货进度）记录正确。
  - **账号**：主账号 `15060038842`（或配置的收货人账号 `18006931939`）——签收/确认收货方。
- ⚠️ 签收等式校验（服务端实测拦截）：四项合计超/不足发货量、合格数为负、非整数/超精度、跨行串数，均 400。
- ⚠️ **重复签收 = 409 且不双扣库存**；同一批次只能确认一次。
- ⚠️ 签收后**不能再手工新增一张入库单**，否则合格数重复入库。

## 6. 查看库存

**实时库存查询**
- 菜单：左侧 `库存管理`（或 `仓库管理`）→ `实时库存查询`（路由 `/warehouse/stocks`）
- 操作：按「机构 / 仓库 / 物料」筛选查询。
- **账号**：任意账号（`15060038842` / `18006931939` 均可，只读查询）。
- 预期（完整链路终态）：**供货仓 0 件，申购方收货仓 10 件**（若第 5 节合格 10）。
- 核对字段：`计划数量` / `可用数量` / `冻结数量`，把上下差异对一遍。

**库存记录（流水核对）**
- 菜单：左侧 `库存管理` → `库存记录`（路由 `/flow_all/procurement_inventory_record`）
- 操作：打开库存流水 / 库存分布 / 成本明细，核对每一笔入、出、报废的出入库及**来源单号**。
- **账号**：任意账号（`15060038842` / `18006931939` 均可，只读查询）。
- 预期：每笔都有对应来源单号；删除、重新登录、重新查询后结果一致；导出单件与查询一致。
- 「库存报表」与明细账核对，无紧张/缺失记录。

## 7. 卡点速查

| 现象 | 原因 / 处理 |
|---|---|
| 登录后卡在登录页 | 没点「同意」**方框**，只点了文字（会跳隐私政策）。回到登录页点方框再登录。 |
| 审核被拒（403/409） | 用错了账号：**创建人不能审自己的单**。退出主账号，换 **1800** 登录再审核。 |
| 付款「确认到账」被拒（403） | 登记人和确认人不能同一人。登记用 1506，确认必须换 1800。 |
| 新建立申购单时选不到协议 | 协议未填**默认单价**或已停用/未启用。回第 1 节把协议补全。 |
| 发货报「超过订单剩余可发数量」 | 本次发货量 > 可发余量。改小数量。 |
| 签收报红字「请填写差异原因」 | 有短少/破损/拒收但没填原因+选补发/结案。补齐再确认。 |
| 签收报 400（四项合计不符） | 合格+短少+破损+拒收 必须 = 发货量；检查是否漏填或算错。 |
| 重复签收 409 | 同一批次已确认过，库存不会双扣，属正常防护。 |
