**需求描述**

**附件上传 / 查看优化（h5 · App）**

**上传态 - 办理 / 发起页（h5）**
· 点击图片上传入口后，图片类附件直接以缩略图呈现，一行 3 张（3n 网格，超出换行）；
· 每张缩略图右上角带删除圆点，点击移除该张；
· 末尾固定一个虚线「+」添加格，点击继续添加图片或文件；
· 文档类（PDF / Word / Excel / PPT / ZIP 等）附件进入同一缩略图网格，以类型图标占位缩略图展示；
· 区域下方展示已上传数量提示（如「已上传 5 个，还可继续添加」），支持图片与文档。

**查看态 - 流程 / 审批详情（h5）**
· 流程节点内的附件区，图片类以缩略图呈现，与上传态一致，点击查看大图；
· 非图片类（PDF / Word / Excel / PPT / ZIP 等）以「文件类型图标在上、文件名在下」的卡片呈现；
· 图片缩略图与非图片图标卡在同一附件区按上传顺序混排；
· 已提交的流程附件在查看态不可删除，仅可预览或下载。

**文件类型图标 - 设计资产（通用）**
· 采用统一文件类型图标体系，覆盖 14 类：PDF / DOC / XLS / PPT / CSV / TXT / IMG / VID / AUD / ZIP / CODE / CAD / MD / UNKNOWN；
· 统一造型：纸张 + 右上折角 + 底部类型色标（类型文字），按类型区分色标（如 PDF 红、DOC 蓝、XLS 绿）；
· 图片 IMG 类在上传态与查看态均用缩略图，不套图标卡；
· 图标体系沿用真实系统现有素材（项目内提供的 14 类图标），不重新绘制。

**附：已知说明**
· 本次仅优化附件的展示形态（上传态缩略图网格、查看态缩略图 / 图标卡），不改变附件存储、权限与通知逻辑；
· 原型见 docs/附件上传优化_原型.html，底部 14 类图标区为设计资产参照。
