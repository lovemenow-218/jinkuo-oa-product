# 金阔OA · 总的需求文档

> 本文档是金阔OA 全部功能需求的**总纲与索引**：汇总项目背景、术语、角色权限、全局规范、功能地图与迭代规划，并为每个功能提供独立的「功能需求描述」文档链接。新增需求时：在本文档「需求清单」追加一条、补充摘要与依赖，并新建对应「功能需求描述」文档。

## 一、项目背景与目标

金阔OA 是一套面向企业的协同办公与流程审批系统，覆盖流程审批、会计审批、备用金、员工档案、消息通知、预警等模块，分 **h5 / App** 与 **web 管理后台** 两个端。

**建设目标**
- 统一各端需求口径，避免 h5 / web 同一功能出现分歧；
- 沉淀跨功能共享的全局规范（通知文案、图标、跨端已读同步、权限模型）；
- 为每个功能维护一份可追溯、独立的功能需求描述文档，作为开发 / 测试 / 实施统一基线。

## 二、术语表

| 术语 | 说明 |
| - | - |
| 商家主体（businessId） | 系统数据隔离维度；同一商家主体数据独立，跨主体互不可见、互不读写。 |
| 流程 / 流程实例 / 节点 | 审批流程模板、其一次执行实例、实例中的处理环节。 |
| 单据 | 业务载体，如备用金申请单、合同等，流转于流程节点间。 |
| 审批处理人 / 抄送人 | 节点待审批者 / 仅知会者。 |
| 会签 / 或签 | 多人节点需全部通过（会签）或任一通过（或签）。 |
| 待我审批 | 流程流转到当前用户、其成为某节点待审批处理人时的事件；在消息通知中作为独立通知类。 |
| 还款预警 | 备用金申请按【还款日期】生成的预警通知类，消息通知中第 5 类；含常规 / 临近 / 逾期档位。 |
| 权限点（rbac） | 控制功能 / 按钮可见性的最小权限单元，按角色分配。 |
| 站外推送 / 系统通知 | 在 App / 网页之外（如手机系统通知、类微信消息）触达用户的提醒方式，区别于站内消息中心。 |

## 三、角色与权限

| 角色 | 说明 | 典型权限范围 |
| - | - | - |
| 商家管理员（主账号） | 商家内最高权限，可配置流程、查看全部数据 | 全量管理权限 |
| 员工（含会计 / 出纳 / 人事等业务角色） | 按分配的权限点获得功能 / 按钮可见性 | 仅本人被授权功能，如会计审批、出纳办理、员工档案管理等 |

- 权限模型：基于 rbac 权限点体系，按角色分配；部分功能按权限点控制 Tab / 按钮可见性（如员工档案「离职交接」Tab、会计审批节点「预览」按钮仅处理人可见、预警管理菜单仅会计 / 管理角色可见）。
- 越权约束：未授权角色不可见对应功能 / 按钮，接口层按身份鉴权。

## 四、全局规范

### 1. 消息通知
- **统一主文案**：「【提交人】提交了【流程名称】，请处理」，**不分场景**（提交、流转、会签 / 或签均同一句）。
- **通知图标**：紫色「审」字 = 待我审批类；「警」字 = 还款预警类；其余类沿用各自图标。
- **跨端已读同步**：h5 与 web 消息中心已读状态实时同步。
- **通知分类（两端口径统一，站内）**：@我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 / 还款预警（第 5、6 类）。
- **待我审批 vs 待办**：通知为只读事件提醒；【审批任务 - 待我处理】为可操作清单；同一单据两者并存，属预期。
- **站内 vs 站外**：站内通知在消息中心承载；站外推送（系统通知）将站内六类通知（@我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 / 还款预警）统一接入现有站外通道，使接收人在系统外也能收到提醒，详见《信息推送（站外推送）》。

### 2. 端 / 模块划分口径
- h5 / App：面向移动端员工，承载审批、通知、预警提醒等。
- web 管理后台：面向管理员 / 后台操作，承载消息中心、预警管理、会计审批配置、员工档案等。

## 七、各功能摘要

### 1. 离职流程一键交接
员工档案新增「离职交接」Tab（按权限点控制可见性），支持按离职人 / 接收人发起一键交接，覆盖审批待办、发起中流程、权限点、文档归属四类范围，含三步执行弹窗与交接状态（待执行 / 执行中 / 已完成 / 部分失败 / 已撤回）跟踪，支持搜索与导出。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/KxeVd9HCkoOol9xDYQycc8UMnPg)

### 2. 会计审批-合同关联补充需求
会计审批表单新增「是否签订」下拉（是 / 否，默认空必填）；选"是"展开「合同关联」「合同收款账号」并支持合同选择弹窗，选"否"或清空时隐藏并清空两字段，避免脏数据随表单提交。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/YFfcdfStGo6kfyxS876cXC5gnXd)

### 3. 备用金审批-会计审批页面优化（还款日期）
h5 审批页与 web 同意弹窗均新增必填「还款日期」字段，提供一年 / 半年 / 一个月快捷选项与手动选择，限制不早于今天，双端字段顺序与提交逻辑保持一致。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/Qs3TddnPboV1LSxjI94cjveLnBc)

### 4. 会计审批完成表单预览
h5 / web 流程详情的会计审批节点新增「预览」按钮（仅会计 / 出纳办理处理人可见），只读展示该节点审批时提交的完整表单内容（含附件可点击查看），不允许编辑或再次提交。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/FFZRdHTuMoBEzixsIRqcaMnenYb)

### 5. web 消息通知
web 管理后台顶部「对话气泡」图标改为消息通知入口，独立消息中心承载 @我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 五类通知，支持全部 / 未读筛选、批量已读，与 h5 端跨端同步已读状态。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/UsBCdHI7LoIgNpxFFcQcbbPenMd)

### 6. 消息通知优化（h5）
h5 首页新增通知入口，通知列表承载评论 @ / 审批通过 / 审批驳回 / 抄送 / 待我审批 五类通知（第 5 类「待我审批」为本次新增），@ 选人仅限流程内参与人，点击通知定位到对应节点。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/DYcDdHE0do9XyrxkUvKcVHdqn4d)

### 7. 备用金还款预警通知
备用金还款预警通知，档位按还款期天数 T 计算：还款期上限一年（T ≤ 366），<span style="color:#c00000">候选档位为「提前 30% R = ⌈0.3 × T⌉ + 还剩 30 天（仅 T > 60 启用）+ 还剩 7 天 + 还剩 1 天 + 到期当天」，30 天档启用后相对档须 R ≥ 40 才发（等价 T ≥ 131，与 30 天档至少隔 10 天），并做 D=3 去重（相对档与固定档 30/7/1 相差 ≤3 天时舍相对档；「1 天 → 到期当天」为语义必需对不参与去重），共 6 个区间（1 / 2~7 / 8~33 / 34~60 / 61~130 / 131~366），T ≤ 130 最多 4 档、T ≥ 131 固定 5 档</span>。文案与颜色按常规提醒 / 临近提醒 / 逾期提醒区分；会计审批处理人（会计侧）确认该笔单据已还款后，其全部列表卡片与会计侧详情页同步隐藏「确认已还款」入口并展示已还款状态；确认成功后系统自动向申请人发送一条「还款完成」通知，该笔单据全部预警与逾期提醒停止。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/HSeodH0ElowJYZxlXOScFGL0nCe)｜档位逐日对照表见《预警档位明细_一年》（附件，含 1~366 天全量）

### 8. 预警管理页面（下版本新建）
web 管理后台新增「预警管理」一级菜单（按权限点控制可见性，仅会计审批处理人及相关管理角色可见），作为预警通知的统一管理入口与跳转目标：列表展示全部预警单据（流程名称 / 申请人 / 所属部门 / 备用金金额 / 还款日期 / 剩余或逾期天数 / 当前阶段 / 状态 / 预警起始时间），支持按状态、阶段、申请人、所属部门、时间范围筛选与关键字搜索；支持按关键列排序（默认按剩余 / 逾期天数升序）与按当前筛选 + 排序结果导出 Excel（导出文件名按规则生成）；提供预警详情时间线、确认已还款（仅该笔会计审批处理人可操作，管理角色仅可查看台账，二次确认、终态不可撤回）与批量确认（逐笔生效、每笔向申请人发送一条「还款完成」通知）；已读状态仅属消息中心「还款预警」类通知，预警管理详情时间线为只读台账、查看不触发任何通知的已读变更。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/MjlPdoVUFoZL8gxUlwmclXmOnbh)

### 9. 信息推送（站外推送）（下版本新建）
将站内消息中心六类通知（@我的 / 审批通过 / 审批驳回 / 抄送我的 / 待我审批 / 还款预警）统一接入现有站外推送通道，使对应接收人在系统外（手机系统通知 / 类微信消息）也能收到提醒；站外文案、接收人、频率、幂等、已读同步均与站内一致，不新增通道类型。原《预警通知系统推送》已并入本需求。
→ 详见：[功能需求描述](https://dcn9hn38h4tk.feishu.cn/docx/Pjwxd9gd2oGJMZxrnllcF3rZnWh)

## 八、功能间依赖与关联

- 备用金还款预警通知 → 下版本立项「预警管理」web 页面：预警通知（消息中心第 5 类）点击跳转由暂跳流程详情切换为该页面；预警通知本身仍在消息中心承载，两者并存。
- 备用金还款预警通知 ← 《备用金审批-会计审批页面优化（还款日期）》：预警档位以【还款日期】为唯一基准；还款期上限一年（业务确认），【还款日期】可选范围为「当前日期 ~ 当前日期 + 1 年」。
- 信息推送（站外推送）→ 依赖「备用金还款预警通知」（站内预警已定义）与现有信息推送通道；将站内六类通知统一接入站外推送，不新增通道类型；原《预警通知系统推送》已并入本需求。
- h5 / web 消息通知口径统一：六类一致（含还款预警）、主文案一致、跨端已读同步。
- 待我审批通知依赖流程流转事件，与【审批任务 - 待我处理】待办并存。
- 离职流程一键交接与员工档案权限联动（按权限点控制可见性）。
- 会计审批页面优化（下版本归组迭代项）包含：会计审批-合同关联补充需求、备用金审批-会计审批页面优化（还款日期）、会计审批完成表单预览；三者均依赖备用金申请会计审批环节。
