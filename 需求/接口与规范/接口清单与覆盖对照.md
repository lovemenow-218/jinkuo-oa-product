## 测试环境实测结论（2026-10-09，https://h5cs.fzjinkuo.com）

**全量 161 条：153 通过 / 5 跳过 / 3 缺陷监控 / 0 失败**

| 模块 | 结果 |
| --- | --- |
| 单元测试（32） | 全通过，不联网 |
| 审批 flow（60） | 56 通过 / 2 跳过 |
| 人事 hr（22） | 全通过 |

| 报表 report（13） | 通过（银行账户 CRUD 转缺陷监控） |

**环境事实（写用例时必须知道）**：

1. **测试环境与生产是同一个后端数据库**——h5cs 上已存在生产创建的模板 6163~6167，
   账号、门店、业务数据完全一致，只是 H5 域名不同。**不要以为测试环境可以随便造数据。**
2. **对象存储未开启**：附件上传返回 500 `attachment upload storage is disabled`
   → 上传类用例自动跳过（用例已识别该错误并 skip，不会误报失败）。
3. **新增银行账户接口恒定 500**（传空对象 `{}` 也一样），属服务端缺陷，与字段名无关。
4. 首次接入新环境要先建模板：`python scripts/create_lhlh_templates.py --env=test`
