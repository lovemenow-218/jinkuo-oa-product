# 金阔 OA · 产品需求与原型

工作交接、离职审批两个功能的需求文档和原型。

## 打开方式

- **原型**：用浏览器打开对应的 `.html` 文件即可。`tokens.css` 必须和 HTML 放在同一目录，否则页面样式会丢失。
- **需求**：`.md` 文件用任意 Markdown 编辑器或直接文本编辑器打开。
- **需求结构图**：`.xmind` 文件用 Xmind 打开。

原型分两种：带批注版是静态展示稿，按角色分页，每屏旁边有规则说明；可交互版可以点击操作，用来走通完整流程。

## 口径说明

- 工作交接由员工本人发起，只处理本人名下的任务与节点；权限点移交归离职交接，工作交接不处理权限点。
- 接手人与新处理人须为在职、与本人同属一个门店、不可与本人相同。
- 离职审批分三阶段：离职申请审批 → 逐项办理离职交接 → HR 确认离职。审批链在发起时即全部显示，交接节点到交接阶段才展开。
- 两端数据互通：h5 与 web 看到的是同一张单、同一份状态。
- 本期仅 qt 品牌测试门店开放，通过代码按门店写死控制，不做权限点控制。
- 设计参照钉钉的交互与信息架构，不复刻其文案、视觉与品牌。

本方案为产品设计参考，具体实施请结合公司合规与法务要求确认。
