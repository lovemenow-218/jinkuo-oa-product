## 打开方式

- **原型**：用浏览器打开 `.html` 文件。部分原型依赖 `tokens.css`，该文件已放在对应原型文件夹内，不要和 HTML 分开。
- **需求**：`.md` 文件用 Markdown 编辑器或文本编辑器打开；`.xlsx`、`.csv` 用表格软件打开。
- **需求结构图**：`.xmind` 文件用 Xmind 打开。
- **原型分两种**：带批注版是静态展示稿，按角色分页，每屏旁边有规则说明；可交互版可以点击操作，走通完整流程。

## 说明

- 「历史版本（旧合并版）」里的工作交接、离职审批需求是拆分前的旧稿，部分口径已过时，以「工作交接」「离职审批」文件夹里的拆分版为准。
- 需求里标「待确认」的条目是评审时要定的问题，未定之前按文中写的默认口径处理。
- 工作交接由员工本人发起，只处理本人名下的任务与节点；权限点移交归离职交接。
- 接手人与新处理人须为在职、与本人同属一个门店、不可与本人相同。
- 离职审批分三阶段：离职申请审批 → 逐项办理离职交接 → HR 确认离职；审批链在发起时即全部显示，交接节点到交接阶段才展开。
- 本期仅 qt 品牌测试门店开放，通过代码按门店写死控制，不做权限点控制。
- 设计参照钉钉的交互与信息架构，不复刻其文案、视觉与品牌。

本仓库为产品设计参考，具体实施请结合公司合规与法务要求确认。
